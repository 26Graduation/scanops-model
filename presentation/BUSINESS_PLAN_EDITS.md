## 4.3 네 가지 무기

### ⑤ "오탐률 18%(Grok 64%의 1/3)" — 두 번 나온다. 둘 다 정정

| | |
|---|---|
| **현재** | "적대적 OWASP서도 **오탐률 18%**, Grok 64%의 **1/3**" (4.3 세 번째·네 번째 항목에 중복) |
| **실측** | ① 이 수치의 재현 근거를 현재 산출물에서 찾지 못했다. ② **더 중요한 것**: 제품이 실제로 하는 과제(패치 전후 구분)에서 **문제는 오탐이 아니라 미탐**이다 — 현 운영점 τ=0 의 쌍 4분류에서 **둘 다 "안전"이라고 답한 비율이 CleanVul 52.9% / PrimeVul 78.5%** 다. |
| **수정안** | "오탐률"을 대표 지표로 쓰지 않는다. 쓰려면 **(벤치 · 운영점 · 그때의 recall · 유병률 가정)** 을 붙인다. 예: "CyberNative 154(비쌍·독립 출처)에서 현 배포 운영점 precision **0.9123** @ recall 0.6753, FPR 0.065 — **50:50 균형셋 가정**." **PR 리뷰 과제에서는 이 문장이 성립하지 않는다.** |

### ⑥ "실제 CVE·독립 벤치 우위" (F1 67.6/79.1 vs 43.7/65.5)

| | |
|---|---|
| **현재** | "CVEfixes·CyberNative에서 상용 **Grok을 능가**(F1 67.6/79.1 vs 43.7/65.5)" |
| **실측** | Grok 비교는 이전 세션 산출물(`rebuild/out/compare_grok_report.json`)에 있고 **모델 ID·호출일이 표에 붙어 있지 않다.** 그리고 현재 v1 의 같은 벤치 F1 은 CyberNative **0.7761** / CVEfixes **0.8046**(OP-0) 이다. |
| **수정안** | ① 비교 상대의 **모델 ID·호출일·프롬프트**를 표에 적는다. ② **F1 옆에 자명 기준선**(CyberNative 0.6667 / CVEfixes 0.6751)을 병기한다. ③ 최신 대조는 **Claude Opus 5 PARITY** 로 갱신한다(표3). |

### ⑦ "PR 자동 분석" — 실제로 재는 능력을 적는다

| | |
|---|---|
| **현재** | (기능 소개에 성능 수치 없음) |
| **실측** | **현 배포의 PR 쌍 판별은 0.4600 — 우연(0.50) 아래**다. 오늘 `[DIFF]` 마커를 제품에 붙였고, 같은 조건 측정값은 **0.6050** [0.545, 0.668] 이다(위치 상쇄 후 +0.1450 [+0.0650, +0.2225]). 사전등록 게이트는 **동점률 하나로 미통과**(`CB-PARTIAL`). |
| **수정안** | "PR 자동 분석"을 소개할 때 **이 수치 없이 광고하지 않는다.** 문장 예: "PR 변경 맥락을 프롬프트에 넣어 패치 전후 구분 정확도를 0.46 → 0.61 로 올렸다(200쌍, 위치 상쇄, CI 하한 +0.065). **아직 우연(0.50)을 갓 넘긴 수준이며 다음 관문은 학습 데이터의 '둘 다 안전한 변경' 쌍 결손을 메우는 것이다.**" **"학습으로 더 올렸다"고 쓰지 않는다** — 올랐지만 안전 판본 오탐이 6.7배가 되어 채택하지 않았다. |

## 4.2 경쟁사 비교

### ⑧ 가격표는 그대로 두되, 성능 칸을 추가하지 않는다

가격 비교는 공개 정보이므로 유지. **다만 같은 표에 "성능 우위" 칸을 붙이지 않는다** —
Snyk·Semgrep·GitHub Advanced Security 와 **같은 벤치에서 비교한 측정이 없다.**
비교 문장을 쓰려면 그 도구들을 같은 데이터에 돌려야 하고, 이번 세션에서 하지 않았다.

## 전체에 적용할 서술 규칙 (계획서 어디에나)

1. **주 지표는 AUC** + 명시된 운영점 1개(현행 OP-0, τ=0, greedy).
2. **F1 을 쓸 때는 자명 기준선(균형셋 0.6667)을 같은 표에.** 커밋 쌍 벤치 2종은 어떤 운영점에서도 그 선을 못 넘는다.
3. **"오탐률 X%"는 (벤치 · 운영점 · 그때의 recall · 유병률 가정) 없이 쓰지 않는다.**
4. **내부 벤치와 외부 벤치를 같은 칸에 넣지 않는다.**
5. **외부 모델 비교에는 모델 ID·호출일·프롬프트 조건**을 반드시 붙인다. 오늘 조건에서는
   **`temperature=0` 이 우리 쪽에만 적용된다**(Claude 5 계열은 sampling 파라미터를 거부한다)는 사실도 함께 적는다.
6. 금지어: **"완성", "증명", "유일", "압도"**.
